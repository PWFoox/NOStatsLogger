# NOStatsLogger

BepInEx mod for *Nuclear Option* that automatically tracks flight statistics, combat performance, and mission outcomes, featuring an in-game dashboard UI.

## Features
- **Automatic Tracking**: Records flight duration, air/ground kills, and sortie status (landed, ejected, shot down).
- **In-Game Dashboard**: Modern UI in the main menu with KPI metrics and aircraft fleet filtering.
- **Local CSV Storage**: Saves all flight logs locally for easy review and analysis.

> The mod is being developed with AI assistance, so bugs are possible. Please report any issues!
